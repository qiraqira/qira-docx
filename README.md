# Qira DOCX — free DOCX editor for Windows

Open, edit and save Word documents (.docx, and old .doc) for free. No account, no ads, works offline.

- Website and online editor: https://docx.qirastudio.com
- Download: see [Releases](https://github.com/qiraqira/qira-docx/releases/latest)

Windows 10 and 11, 64-bit. Made by [Qira Studio](https://qirastudio.com).
